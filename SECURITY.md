# Segurança

- Não use este simulador contra servidores ACS de clientes ou ambientes de produção.
- Não versione `.env`, senhas, tokens ou chaves privadas.
- Mantenha `ALLOWED_ACS_HOST=demo.orbysync.tec.br` no laboratório oficial.
- Use seriais iniciados por `SIM` para impedir confusão com CPEs reais.
- Revogue imediatamente qualquer credencial publicada por engano e remova-a do histórico Git.
